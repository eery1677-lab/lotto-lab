# 로또 확률 연구소

동행복권 로또 6/45 전 회차를 수학적으로 분석하는 로컬 웹사이트입니다. 맥과 윈도우에서 똑같이 동작합니다.
파이썬 표준 라이브러리만 쓰므로 따로 설치할 패키지가 없습니다.

> **이 사이트는 당첨 번호를 예측하지 않습니다.** 로또 추첨은 매 회차 독립이고, 모든 조합의 1등 확률은 1/8,145,060 으로 같습니다.
> 이 사이트가 해 주는 것은 ① 그 사실을 실제 자료로 검증해 보여 주기, ② **당첨됐을 때 나눠 가질 사람이 적은 조합**을 골라 주기(1등 기대 수령액 약 +15~25%)입니다.

## 실행

| | 방법 |
|---|---|
| 맥 | `start_mac.command` 더블클릭 (처음엔 우클릭 → 열기). 또는 터미널에서 `python3 server.py` |
| 윈도우 | `start_windows.bat` 더블클릭. 또는 `python server.py` |

- 주소: <http://127.0.0.1:3600> (이 컴퓨터에서만 접속)
- 아이패드·폰에서도 보려면: `python3 server.py --lan` 후 `http://(맥 IP):3600`
- 포트 바꾸기: 환경변수 `LOTTO_PORT=3700`
- 맥에 파이썬이 없으면: 터미널에서 `xcode-select --install`

## 화면

1. **요약** — 최신 회차, 핵심 결론, 무작위성 검정 판정, 최근 12회
2. **번호 만들기** — 운영체제 암호학적 난수 + 비인기 조합 필터(하위 5/10/20%)
3. **내 번호 검사** — 인기도, 1등이면 나눌 인원, 2002년부터 매주 샀다면의 결과
4. **무작위성 검정** — 번호 빈도·합계·홀짝·직전 회차 반복·연속번호를 정확한 이론 분포와 카이제곱 비교
5. **예측법 검증** — 핫/콜드/미출현/역대 최다/지난주 번호/황금 패턴/빈도 가중을 워크포워드로 실제 회차에 적용
6. **인기 번호 분석** — 등수별 당첨자 수로 추정한 번호별 인기도, 조합 모양 효과, 표본 밖 검증
7. **AI 상담** — LM Studio 로컬 모델. 코드가 계산한 사실만 쓰게 하고, 자료에 없는 숫자는 답 아래 표시
8. **로또의 원리** — 추첨 방식, 도박사의 오류, 기대값·세금, 해외 사례(만델, Cash WinFall), AI 예측의 한계

## LM Studio

- LM Studio → Developer → **Status: Running** (기본 `http://127.0.0.1:1234`)
- AI 상담 화면에서 모델을 고르면 기억합니다. ● = 이미 로드된 모델.
- 맥(M5 Pro Max 64GB) 추천: 규칙을 잘 지키는 **Qwen 27B** 또는 **Gemma 4 31B/26B**. 빠른 답이 필요하면 MoE 모델(Qwen 35B-A3B 등).
  작은 모델(4B 급)은 통계를 잘못 읽는 경우가 있어 코드가 결론 문장을 미리 만들어 줍니다.
- 모든 요청에 `reasoning_effort: "none"`(생각 끄기)을 보내고, 모델이 거절하면 빼고 다시 보냅니다.

## 자료

- 출처: 동행복권 공식 조회 `https://www.dhlottery.co.kr/lt645/selectPstLt645Info.do?srchLtEpsd=all`
  (회차·번호·보너스·1~5등 당첨자 수와 1인당 금액·판매액)
- `data/draws.json` 에 저장. 토요일 추첨 후(21:30 이후) 화면을 열면 자동으로 새 회차를 받고, 실패하면 저장된 자료로 동작합니다.
- 수동 갱신: `python3 lotto_data.py` 또는 화면 왼쪽 아래 "지금 새 회차 확인".

## 파일

| 파일 | 역할 |
|---|---|
| `server.py` | 웹 서버(포트 3600), API, LM Studio 연결·프롬프트 |
| `analysis.py` | 모든 통계 계산(검정·예측법 검증·인기 모델·번호 생성) |
| `lotto_data.py` | 공식 자료 받기·검사·저장 |
| `web/` | 화면(index.html, app.js, style.css) — 외부 라이브러리 없음, 오프라인 동작 |
