# 로또 확률 연구소

동행복권 로또 6/45 전 회차를 수학적으로 분석하는 로컬 웹사이트입니다. 맥과 윈도우에서 똑같이 동작합니다.
파이썬 표준 라이브러리만 쓰므로 따로 설치할 패키지가 없습니다.

> **이 사이트는 당첨 번호를 예측하지 않습니다.** 로또 추첨은 매 회차 독립이고, 모든 조합의 1등 확률은 1/8,145,060 으로 같습니다.
> 이 사이트가 해 주는 것은 ① 그 사실을 실제 자료로 검증해 보여 주기, ② **당첨됐을 때 나눠 가질 사람이 적은 조합**을 골라 주기(1등 기대 수령액 약 +15~25%, 1,000원당 기대 환급 평균 약 500원 → 약 550~580원, 이론 최대 약 660원)입니다. 어떤 번호도 기대값이 1,000원을 넘지 않습니다.

## 실행

| | 방법 |
|---|---|
| 맥 | `start_mac.command` 더블클릭 (처음엔 우클릭 → 열기). 또는 터미널에서 `python3 server.py` |
| 윈도우 | 바탕화면 **"로또 확률 연구소"** 아이콘(꺼져 있으면 서버를 창 없이 켜고 전용 크롬 창으로 엶). 또는 `start_windows.bat`, `python server.py` |

- 주소: <http://127.0.0.1:3600> (이 컴퓨터에서만 접속)
- 아이패드·폰에서도 보려면: `python3 server.py --lan` 후 `http://(맥 IP):3600`
- 포트 바꾸기: 환경변수 `LOTTO_PORT=3700`
- 맥에 파이썬이 없으면: 터미널에서 `xcode-select --install`

**캐릭터 '로또'** — 로또 공 박사(3D). 사이드바·AI 상담·주간 브리핑·추첨기 옆에 나오고, 끌어서 360도 돌려 볼 수 있습니다(더블클릭하면 한 바퀴). 표정 7가지, 인터넷 없이 동작(three.js 를 `web/vendor` 에 포함).

## 화면

1. **요약** — 최신 회차, 핵심 결론, 무작위성 검정 판정, 최근 12회
2. **번호 만들기** — 운영체제 암호학적 난수 + 비인기 조합 필터(하위 5/10/20%)
3. **내 번호 검사** — 인기도, 1등이면 나눌 인원, 2002년부터 매주 샀다면의 결과
4. **내 구매 기록** — 산 번호 저장, 결과 자동 확인(등수·세후 금액), 손익·환급률, 월 예산 경고
5. **무작위성 검정** — 번호 빈도·합계·홀짝·직전 회차 반복·연속번호를 정확한 이론 분포와 카이제곱 비교
6. **예측법 검증** — 핫/콜드/미출현/역대 최다/지난주 번호/황금 패턴/빈도 가중을 워크포워드로 실제 회차에 적용
7. **인기 번호 분석** — 1등 자동/수동 구분 + 5등 당첨자 수로 추정한 인기도, 표본 밖 검증, 기대 환급 상한
8. **AI 상담** — LM Studio 로컬 모델. 코드가 계산한 사실만 쓰게 하고, 자료에 없는 숫자는 답 아래 표시
9. **로또의 원리** — 추첨 방식, 도박사의 오류, 기대값·세금, 해외 사례(만델, Cash WinFall), AI 예측의 한계

## LM Studio

- LM Studio → Developer → **Status: Running** (기본 `http://127.0.0.1:1234`)
- AI 상담 화면에서 모델을 고르면 기억합니다. ● = 이미 로드된 모델.
- 맥(M5 Pro Max 64GB) 추천: 규칙을 잘 지키는 **Qwen 27B** 또는 **Gemma 4 31B/26B**. 빠른 답이 필요하면 MoE 모델(Qwen 35B-A3B 등).
  작은 모델(4B 급)은 통계를 잘못 읽는 경우가 있어 코드가 결론 문장을 미리 만들어 줍니다.
- 모든 요청에 `reasoning_effort: "none"`(생각 끄기)을 보내고, 모델이 거절하면 빼고 다시 보냅니다.

## 모델 고르기 (자동 채점)

사이트를 켠 상태에서 이 폴더의 터미널에서 실행합니다. 시험지 24문항(기능 사용·연구 출처·정직성·기타)을 모델마다 묻고,
정답(공식 자료로 코드가 계산)과 비교해 점수를 매깁니다. 질문은 읽기 전용이라 구매 기록을 바꾸지 않습니다.

```bash
python3 model_eval.py              # LM Studio 에 로드된 모델만 (윈도우는 python)
python3 model_eval.py --all        # 설치된 모든 대화 모델 — 큰 모델을 차례로 불러오니 시간·메모리 주의
python3 model_eval.py --models "qwen/qwen3.6-27b,google/gemma-4-31b"
```

결과는 `data/model_eval.json`(컴퓨터마다 따로)에 저장되고, AI 상담 화면의 **모델 성적표**와 모델 목록의 ★로 보입니다.
1등 모델은 주간 브리핑의 기본 모델이 됩니다. 맥(M5 Pro Max 64GB)에서는 Qwen 27B·35B-A3B, Gemma 4 12B/26B/31B 를 `--all` 로 비교해 보세요.
